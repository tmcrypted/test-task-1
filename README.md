# Замер скорости интернета

Консольный скрипт 10 раз последовательно скачивает ответ с указанного HTTP- или HTTPS-адреса и рассчитывает среднее время запроса, общий объём данных и среднюю скорость загрузки.

## Требования

- Node.js 18 или новее (внешние пакеты не нужны).

## Запуск

```bash
node index.js https://example.com/
```

Эта команда подходит для базовой проверки запуска. Для более показательного замера укажите прямую ссылку на крупное изображение или другой файл.

Скрипт выполнит запросы по очереди и выведет:

- среднее время одного запроса в миллисекундах (`ms`);
- общий объём тел ответов в байтах и мегабайтах (`MB`, 1 MB = 1 000 000 байт);
- среднюю скорость загрузки в десятичных мегабайтах в секунду (`MB/s`).

Время запроса измеряется от его начала до полного чтения тела ответа. Средняя скорость — это общий объём тел ответов, делённый на суммарное время всех десяти запросов. Ответы сервера с кодом вне диапазона 200–299 и ошибки сети выводятся в stderr; в таком случае скрипт завершается с ненулевым кодом.

## Проверка

При успешном запуске в выводе будет `Requests completed: 10`, среднее время (`ms`), общий объём и скорость (`MB/s`). Чтобы проверить обработку ошибки аргумента, запустите `node index.js` без URL: скрипт покажет подсказку и завершится с ненулевым кодом.

Автоматические тесты запускаются командой:

```bash
npm test
```

Тесты используют локальный HTTP-сервер и проверяют 10 последовательных полных ответов, подсчёт больших и пустых ответов, редиректы, HTTP-ошибки, обрыв соединения и неверные аргументы. Зависимости устанавливать не нужно.
